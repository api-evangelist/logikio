# Logik.io

> Logik.io is a headless, composable, API-first CPQ (Configure, Price, Quote) and product-configuration engine. It powers guided configuration, pricing, and quoting for complex products across Salesforce CPQ/Commerce and any headless front end, and computes Bills of Materials (Sales, Manufacturing, Custom). Acquired by ServiceNow; now also marketed as ServiceNow CPQ / Logik.ai. The developer surface (api-docs.logik.io, github.com/logikioopensource) remains live.

This file was generated by the API Evangelist enrichment pipeline from Logik.io's published OpenAPI specs and developer documentation.

## APIs

- [Runtime Configuration APIs (v2)](https://api-docs.logik.io/): Start, retrieve, update/save configurations; access Sets; get BOMs. v2 media type application/vnd.logik.cfg-v2+json; required for Product Picker Fields.
- [Runtime Configuration APIs (v1)](https://api-docs.logik.io/): v1 (application/json) configuration + BOM operations.
- [Admin API - Managed Tables](https://api-docs.logik.io/): CRUD over managed data tables, columns, rows, metadata, and CSV import/export.
- [Admin API - Blueprints](https://api-docs.logik.io/): Bulk import/export of blueprints and job status.

## Auth

- HTTP Bearer tokens. Runtime Token (Admin > Runtime Clients; Origin must be allow-listed) for Configuration/BOM APIs; Admin Token (Admin > Utilities > Admin API Keys) for Admin APIs.
